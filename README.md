# QC SMC

ระบบตรวจสอบคุณภาพงานติดตั้งแผ่น Precast Façade (เว็บไซต์)

- `index.html` คือหน้าเว็บทั้งหมด (ไฟล์เดียว) เปิดผ่าน GitHub Pages
- ข้อมูลและรูปเก็บใน Supabase เข้าใช้ได้เฉพาะอีเมลที่อยู่ในตาราง `members`
- `supabase-setup.sql` ใช้ตั้งค่าฐานข้อมูลครั้งแรก
- `src/` คือตัวเชื่อม Supabase และหน้าลงชื่อเข้าใช้ (ประกอบเข้า index.html แล้ว)

ไฟล์นี้มีเฉพาะ publishable key ซึ่งเปิดเผยได้ ข้อมูลงานถูกป้องกันด้วย Row Level Security
